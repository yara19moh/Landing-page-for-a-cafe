# Blossom & Bean – Café Landing Page

A concept landing page for a fictional café, designed and built as a portfolio project.

## Features
- Responsive layout for desktop and mobile
- Interactive menu with tabs (Coffee, Cold Drinks, Shakes & Sweets)
- Best sellers section
- Custom logo and a palette of chocolate, aloewood, milk tea and sakura pink
- Light and dark mode

## Built with
HTML, CSS and a little JavaScript
